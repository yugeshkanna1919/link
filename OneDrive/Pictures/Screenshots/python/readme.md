# Student Management System

A simple **console-based Student Management System** implemented in Python. This system allows you to **add, view, search, and delete student records** using dictionaries and sets.

---

## Features

- **Add Student**: Add a new student with unique ID, name, age, branch, and mark.
- **View Students**: Display details of all students.
- **Search Student**: Search for a student by their unique ID.
- **Delete Student**: Remove a student by their ID.
- **Input Validation**: Ensures valid input for IDs, age, marks, and branch selection.
- **Simple Menu Interface**: Easy-to-use text-based menu for user interaction.

---

## Technologies Used

- **Python 3**
- Built-in data structures: `dict`, `set`, `tuple`
